# Nascent Love 验证期 BOM

团队 **binomial** · 项目 **Nascent Love** · 板卡 `hardware/toy-sidecar` · 协议 `0.3.0-demo`

验证期只有一块板：ESP32-S3-N16R8。它采集、推断、点灯，经 AO3400A 并联原产品按键；**不驱动电机**。电机、九档逻辑、实体按键都还在原产品控制板上。

单价为 2026-08 国内散件参考价（人民币），不含原产品本体。CSV 源：[`bom.csv`](bom.csv)。接线原理图：[`schematic.svg`](schematic.svg)。

## 验证期未焊（量产项，不要按本表采购来演示）

| 器件 | 原因 |
|---|---|
| NTC ×2（接触面 + 外壳） | 12Hz 接触过温熔断。Demo 未焊；DHT11 不能替代 |
| FSR402 右（GPIO2） | `TOY_HAS_FSR_R=0`，固件不读 |
| 常闭急停拉环 | Demo 用板载 BOOT 键短按代劳 |
| I2S 麦克风 | 本地安全词。Demo 可不焊 |
| HW504 摇杆 / 行空板 K10 | 协议 0.3.0 已删除，不要再买 |

| FSR402 右 | GPIO2 | 未接 |

AO3400A：漏极经 R3 10k 接原按键触点 A（关机态约 3.7V）；源极接触点 B + 原电池负极 + ESP32 GND（三方共地）。原实体按钮保留并联。
