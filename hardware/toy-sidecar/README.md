# toy-sidecar —— 玩具侧协处理板

ESP32-S3-N16R8。负责采集、推断、点灯，以及通过 CD4066 并联原产品按键。

## 最重要的一条

**这块板不驱动电机。** 振动强度自始至终由原产品控制板决定，
本板能做的只是"替人按那个按钮"。这是硬件级的安全边界，
任何把 MOSFET 接到电机上的改动都等于推翻整个安全论证，不要做。

CD4066 的连续电流上限在 10mA 量级，接电机会直接烧片子。

### CD4066 供电已定案：情况 B

2026-08-28 实测原按键：**关机态下两端电压约 3.7V**，短接即通路、电压归零。
3.7V 超过 3.3V，所以情况 A（CD4066 吃 3V3）被否决——3.7V 的信号进 VDD=3.3V 的
模拟开关会通过输入保护二极管往 ESP32 的 3V3 轨倒灌。`NL_CD4066_CASE_A_3V3` 已置 0。

同时实测：**串 1kΩ 短接仍能开机**，说明原板上拉阻值不低（至少 3kΩ 量级），
CD4066 千欧级的导通电阻可以接受，不必换 MOS 管或 PhotoMOS。

| CD4066BE 引脚 | 接到 | 备注 |
|---|---|---|
| 14（VDD） | 原板电池正极 3.8V | **绝不接 ESP32 的 3V3**，S3 推荐 3.0～3.6V |
| 7（VSS） | 原板电池负极 + ESP32 GND | 三方共地 |
| 1 / 2（Switch A 两端） | 原按键触点 A / B | 双向，无方向之分 |
| 13（Control A） | GPIO7，串 1kΩ | 另加 47k～100k 下拉到 GND |
| 14 ↔ 7 | 0.1µF 陶瓷电容 | 就近放 |
| 5 / 6 / 12 | GND | 未用通道的控制脚不要悬空 |

13 脚串的那 1kΩ 是为电池放电末期准备的：VDD 掉到 3.3V 以下时 ESP32 的高电平
会高于 VDD，通过保护二极管往原板灌电流，1kΩ 把它限制在毫安以下。

焊完先不接 GPIO，用杜邦线把 13 脚点到 3.3V 一秒确认能开机，再接 GPIO7。

### 原板按键语义（实测，不是假设）

| 动作 | 效果 |
|---|---|
| 长按约 1s | 电源**取反**：关机态 → 开机并停在第 1 档；开机态 → 关机 |
| 瞬时短接 | 档位循环，**仅开机态有效**，关机态短按毫无反应 |

「长按 = 取反」而不是「长按 = 关机」，这一条决定了 `cd4066.cpp` 的整个状态机：

- 上电**不发任何按键**。盲发一次"对齐用"的长按会把关着的玩具打开。
- 降档不靠短按绕一圈（中途必然经过原板第 9 档，也就是最强档），
  而是走「长按关机 → 长按开机 → 短按上去」，多花约 3 秒。
- `requestOffNow()` 在记录为关机时**什么都不按**，因为那一下长按会变成开机。

原板不回传任何状态，所以 `powered_` / `step_` 都是开环假设。
**关机是唯一可信的已知点**：一次把它关掉的长按之后，记录才重新对齐。

### 电机观测器与标定

`motor_sense.{h,cpp}` 用 MPU6050 判断原板此刻是不是在振动，用来补开环记录的漏洞：
有人手按实体键把玩具打开时，固件仍记为关机，停机指令就会因为「记录为关机」
而不发那次长按。

**硬边界：观测结果永不驱动按键。** 它只修正开环记录和报警，补救交给人。
让一个会被人体动作干扰的信号去按电源键，等于把「设备自己动起来」的权力交给噪声。
停机长按发出后若仍观测到振动，固件保持白灯、置遥测 `flags` bit4、串口喊人，
**不自动补按**。

判据不能复用 `InsertInference::accel_var()`——那是加速度模长的窗口方差，
人拿起玩具和电机转起来都会把它抬高。这里用**一阶差分能量**：电机振动过了
DLPF 42Hz 仍有高频残留，在 12Hz 采样下是相邻样本间的无规则抖动，差分能量高；
人体动作是 1-3Hz 的平滑轨迹，方差可能很大但相邻样本差分很小。

阈值必须在实物上标定，出厂值是占位值，所以 `MOTOR_SENSE_ENABLED` 默认为 **0**——
此时 `MotorSense::state()` 恒返回 `kUnknown`，一行逻辑都影响不到，只每秒打一行
`[motor-cal] jerk=... var=...`。标定步骤：

1. 烧这版固件，串口连上。
2. 跑五种场景各约 10 秒，记下 `jerk` 的范围：关机静置、关机手持晃动、
   开机第 1 档静置、开机第 8 档静置、开机且手持晃动。
3. 取「关机手持晃动」的上界与「开机第 1 档静置」的下界之间，
   填进 `MOTOR_JERK_ON_MG2` / `MOTOR_JERK_OFF_MG2`（留滞回间距）。
4. 把 `MOTOR_SENSE_ENABLED` 置 1 重烧。

如果这两组数在 12Hz 采样下压根分不开，退路是给 `Mpu6050` 加短时高速突发采样
（临时切 DLPF 260Hz + rate 0，连读约 128 个样本），那是另一个任务。

## 强度封顶是怎么实现的

协议 `NL_LEVEL_MAX = 8`，而原板有 9 档。**第 9 档在软件上不可达**，
这就是 90% 封顶在这套硬件上的物理落地方式，不是巧合也不是凑数。
不要为了"能不能再大一点"去改这个常量。

## 停机路径

`stop` 是唯一能穿过所有状态的指令。它的执行不在主循环里排队：
ESP-NOW 回调收到 `NL_CMD_STOP` 的那一行就直接调 `Cd4066::requestOffNow()`
和 `LedRing::renderSafewordNow()`，电机断电与灯变白是同一时刻发生的。

闩锁之后**不会自动恢复，也不能远程恢复**。唯一的解除途径是在 K10 上
同时长按板载 A、B 两键两秒，K10 才会发出 `resume`。App 写 `resume` 会被直接拒绝。

要求物理在场是刻意的：用户喊过停之后设备自己重新动起来，
是这个产品最坏的失败模式，不该由软件单方面决定。

## 烧录

```bash
pio run -e toy-sidecar -t upload
pio device monitor -b 115200
```

首次上电串口会打印本机 MAC，把它填进 k10-controller 的 `config.h`；
反过来把 K10 打印的 MAC 填进本工程的 `PEER_MAC_K10`。验证期不做动态配对。
