短记录已合入或准备合入的 Web UI 小改动，便于联调对照。权威产品结论仍以 `docs/architecture/` 其它文档为准。

## 2026-08-29 · Onboarding 蓝牙说明与健康手环配对

**分支：** `feat/ob-perm-band-pair`（基于当时最新 `main`）

**改动：**

1. **权限页 · 蓝牙说明**  
   由「连接玩具 / 行空板」改为：用于连接萨福产品或健康手环；生理数据只会留在本 App 内使用。

2. **设备配对增加健康手环一步**  
   在玩具（主设备）配对之后，增加「连接健康手环」页；可模拟连接，也可「暂时跳过」。  
   引导结束若已连接，会写入「我的」中的手环连接状态（demo）。

3. **预览缓存**  
   Service Worker 缓存升至 `nascent-shell-v7`，并保证 `#/onboarding` 可强制重新挂载引导，避免旧脚本挡住改动。

**未改：** 玩具主设备配对本身仍沿用 main 上的直连玩具文案与流程；悬置项见 `Web-UI-悬置项.md`。
