## 第二部分：UI设计系统

### 2.1 设计原则（五条铁律）

1. 隐私优先（Privacy-first）：敏感页面默认无露骨元素；隐私优先引导+情感智能界面已被验证可将女性健康类App留存率提升最高38%。
2. 去羞耻化视觉："健康日记/冥想App"风格（暖调、圆角、低饱和），公共场合可坦然打开。
3. 自我探索式语言：全部文案用"觉察、记录、了解"替代"检测、诊断、异常"。
4. 渐进式披露：功能随使用逐步解锁；对话式引导代替问卷。
5. 同意是一等公民：每次采集独立授权、随时撤回；同意记录（时间戳/范围/版本）入库存储。

### 2.2 视觉规范

| **项目** | **规范** | **说明** |
|-|-|-|
| 主色 | 暖珊瑚粉 #F4A7B9 + 雾灰紫 #9B8AA6 | 柔和非刻板，避开"成人红" |
| 功能语义色 | 过冷 #7EB6D9 / 舒适区间 #A8D5BA / 注意 #F5C97B | 禁用红色（红=警报=制造焦虑） |
| 字体 | 中文思源黑体/苹方；图表等宽数字 | 字号≥14pt，关怀低光环境 |
| 使用模式皮肤 | 进入「亲密时刻」自动切换深色低光主题 | 玻璃拟态深色参考 smart-health-monitoring-system |
| 图表 | 平滑曲线+舒适区间带，不给小数点级精确数字 | 数据服务自我觉察，不制造指标焦虑 |

### 2.3 各Tab页面结构

### 2.4 知识卡片模块「身体小课」

**定位：轻量卡片流，让产品从工具升级为陪伴式科普伙伴。原则：科普而非医疗建议（注明"内容仅供参考，不能替代医生"）；去羞耻正向身体观；每张卡60秒读完。**

- 四大栏目：认识身体｜安全与卫生（全量免费）｜读懂信号｜状态与生活
- 卡片结构：提问式标题 → 一句话答案 → 3-5要点 → 展开长文 → 来源与医学审核标注
- 推荐逻辑红线："数据触发科普"而非"数据得出结论"——卡片永远是普适知识，系统只选择哪张卡此刻最相关
- 嵌入时机：Onboarding完成礼（第一张卡）、报告页底部"读懂这次记录"、AI对话中inline发送、每周精选推送
- 订阅划分：安全卫生栏目免费；Plus解锁全部卡库与"21天认识自己"专题打卡

## 第三部分：安全词功能设计（定稿）

### 3.1 功能定位

**安全词是把"知情同意"做成产品功能的核心设计：用户随时可以说出一个词，让一切立即停下。它是信任卖点，也是对《人工智能拟人化互动服务管理暂行办法》"用户控制权"要求的最直接回应。**

### 3.2 技术方案：ESP32 本地监听，音频不上传

| **项目** | **方案** | **依据** |
|-|-|-|
| 芯片 | ESP32-S3（双模SoC，内置向量指令加速神经网络推理） | 乐鑫官方语音方案主力芯片 |
| 识别框架 | 乐鑫 ESP-SR：WakeNet 唤醒词引擎 + AFE 声学前端 | 完全离线运行，无需网络；模型约120-200KB，推理延迟80-300ms，误唤醒率可控制在0.5次/天以下 |
| 自定义安全词 | WakeNet9 支持自定义唤醒词；命令词可用 MultiNet 免训练自定义 | 用户自设词语可落地 |
| 监听上限 | 最多5个以内关键词 | 可覆盖安全词+1-2个辅助指令（如"暂停"） |
| 噪声处理 | AFE 内置 AEC/NS/VAD 等算法 | 应对设备电机运转噪音下的识别 |
| 隐私 | 音频仅在设备端实时处理即丢弃，不存储、不上传任何音频 | 产品页明示："麦克风只在本地倾听，声音永不离开设备" |

### 3.3 多通道触发设计

- 语音：说出安全词（ESP32本地识别，情景模式下持续监听）
- 文字：在AI对话中输入安全词
- 手势：摇一摇手机 / 长按设备实体按键（无网无App时的兜底通道，最可靠）

### 3.4 触发后动作链

1. 设备立即停止运行
2. 退出情景模式/任何剧本状态
3. AI瞬间从人设切换为平静关心状态："已停下，你还好吗？"
4. 界面切换到柔和暂停页（深色低刺激）
5. 可选：本次触发以事实记录写入「身体笔记」（只记录"何时停下"，不做评判性解读），供用户自我觉察

### 3.5 设置项

- 自定义安全词（默认"红灯"）、触发通道开关、触发后动作配置、「测试安全词」按钮（让用户验证它真的有效）

## 第四部分：用户使用旅程

### 4.1 总览

认知种草 → 购买开箱 → 首次启动 → 首次使用 → 日常循环 → 留存转化 → 分享推荐。核心方法：识别每阶段情绪高点与焦虑点，高点放大、焦虑点托底；审计每个隐私触点。

### 4.2 认知与购买

- 种草：知识卡片分享图作为前置素材，绕开成人品类投放限制
- 详情页：突出三项检测报告、隐私发货、实测分贝、安全词功能（差异化信任卖点）
- 收货：中性包装，快递单商品名自定义

### 4.3 首次启动（Onboarding 黄金10分钟）

1. 欢迎页："慢慢来，这里没有标准答案"
2. 年龄验证（滑块轻量确认）
3. 认识AI伴侣：自然语言对话完成人设偏好，而非填表
4. 情境化权限申请（蓝牙/通知各在需要时申请并说明用途）
5. 隐私承诺页：本地/云端二选一（默认本地）
6. 设备配对：连接成功设备轻震确认
7. 强制阅读：卫生与安全指南（3屏）
8. 设置安全词：引导用户亲口测试一次——"说出它，我会立刻停下"
9. 完成仪式：AI送出第一张知识卡《第一次，这些感觉都正常》

### 4.4 首次使用（关键情绪时刻）

| **时刻** | **焦虑点** | **产品响应** |
|-|-|-|
| 取出产品 | 会不会太凉 | 显示接触温度；过冷提示预热 |
| 开始前 | 该用哪一档 | 「我的节奏」默认低档起步；AI引导语 |
| 使用中 | 这样正常吗 | 免打扰模式；心率仅记录不弹窗；安全词全程待命 |
| 结束后 | 刚刚算什么水平 | 30秒生成首份「身体笔记」+关联知识卡 |
| 清洗 | 怎么洗才对 | 清洁SOP卡；传感器确认后推送"可以收纳啦" |

### 4.5 日常循环（Track → Interpret → Act）

- 使用中：温度心率静默采集；接近个人舒适区间轻震提示（可关）；安全词监听全程在线
- 使用后：一句话总结 → 曲线 → 历史对比 → 因素标签 → 自我探索式提问 → 关联知识卡
- 日常：「心绪」Tab 每日一卡+情绪打卡；AI轻量互动，禁止深夜轰炸与挽留话术
- 周报/月报（Plus）：趋势汇总+因素关联洞察

### 4.6 留存与订阅转化

| **时机** | **转化设计** |
|-|-|
| 首次报告生成 | 深度趋势分析模糊预览，Plus解锁 |
| 累计5次使用 | "你的舒适画像已成型"里程碑 |
| 知识卡阅读第10张 | "21天认识自己"专题Plus解锁 |
| 年度节点 | 年度回顾（Pleasure Wrapped式）基础版免费，完整版Plus |
| 永不收费 | 基础报告、温度安全提示、安全词、卫生指南、数据导出与删除 |

### 4.7 分享与推荐

- 报告与知识卡分享图默认全打码；推荐好友得耗材券，不做现金裂变
- 哇塞时刻：年度报告、清洁完成仪式感、AI记住小细节、安全词真的停下来了

### 4.8 隐私触点审计表（定稿）

| **触点** | **数据类型** | **授权方式** | **风险对策** |
|-|-|-|-|
| 安全词麦克风监听 | 音频（实时流） | 功能开关，默认开启可关闭 | ESP32本地识别即丢弃，不存储不上传，页面明示 |
| 设备温度数据 | 产品表面温度 | 本地默认存储 | 云端同步需二次授权 |
| 手环心率 | 生理数据 | Health Connect系统级授权 | 标注"参考性生理反馈" |
| AI对话内容 | 高敏感文本 | 本地优先；记忆逐条可删 | 云端训练默认关闭，opt-in开启 |
| 因素标签 | 自我报告 | 用户主动填写 | 随时清空 |
| 情绪记录与知识卡阅读 | 行为偏好 | 本地记录 | 不用于外部广告画像，一键清空 |
| 账号与年龄 | 身份信息 | 最小化收集 | 支持化名，不强制实名 |

## 第五部分：设置页清单（定稿）

### 5.1 安全与隐私（置顶组）

- 安全词：自定义词语、触发通道、触发后动作、测试按钮
- 应用锁（密码/指纹/面容）
- 存储位置：本地模式/云同步（默认本地，云端需二次授权）
- 授权管理：各项数据授权状态查看与随时撤回
- 数据导出：一键导出个人数据包
- 彻底删除：账号与全部数据删除入口（入口明显，是信任底气）
- 同意记录：何时授权了什么，可追溯

### 5.2 设备管理

- 我的设备（连接状态、电量、固件升级）；传感器自检与校准；清洁提醒频率

### 5.3 AI伴侣

- 人设管理（创建/切换/编辑）；记忆管理（查看AI记住了什么、逐条删除）；对话偏好（话多话少、主动发起频率）；防沉迷提醒阈值（合规要求做成用户可控项）

### 5.4 健康数据接入

- 小米手环绑定/解绑；Health Connect授权状态；心率数据用途说明与单独开关

### 5.5 通用

- 通知：推送总开关、隐晦文案自定义、免打扰时段
- 外观：浅色/深色/跟随系统；"进入使用模式自动切深色"开关
- 订阅：Nascent Love+ 会员管理
- 支持：安全指南回看、知识库、客服（附医学顾问审核团队说明）
- 关于：版本、用户协议、隐私政策、开源组件许可
