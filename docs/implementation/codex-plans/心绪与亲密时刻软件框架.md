# Nascent 心绪与亲密时刻软件框架

> 归档来源：本机 GPT Codex 实施计划（2026-08-28）。历史 Flutter 骨架方案，控制端现已改为共享 Web UI + Android WebView 壳。

## 总结

基于当前 Flutter 骨架、两份产品文档和截图，把 App 串成完整的 A/B/C 三层结构：

- A「心绪」：启动后的第一屏，负责情绪记录、身体科普、历史回看。
- B「亲密时刻」：设备连接状态和三个功能入口。
- C「我的」：安全、设备、隐私、协议等设置。
- 本轮定位为**交互骨架**：页面和核心交互可运行，数据先保存在内存中，不引入数据库和新增 BLE 依赖。

当前已存在的 `HeartState`、心绪页面和亲密时刻页面会继续复用，不重做已有内容。

### 3. 完善亲密时刻入口

保留 `software/app/lib/ui/intimacy.dart` 作为 B 层入口：

- 顶部显示设备连接状态。
- 三个入口固定为：
  - 「情境漫游」：进入故事段落浏览页。
  - 「我的节奏」：进入真实设备控制页。
  - 「身体笔记」：进入记录页。
- 使用大触控区域，保证单手操作。
- 情境漫游本轮只做剧本浏览和开始/结束交互，不自动向设备发送调档指令。
- 身体笔记本轮保存到当前页面内存，显示最近一条记录；不做医疗判断，不生成诊断结论。

### 4. 将控制页对齐“我的节奏”

修改 `software/app/lib/ui/b_control.dart`：

- 页面标题从「控制」改为「我的节奏」。
- 保留并强化：
  - 常驻大号停止按钮。
  - 大尺寸档位 Slider。
  - Slider 只在松手时发送指令。
  - 模式切换控件。
  - 当前连接、使用状态和档位提示。
- 所有设备操作继续唯一通过 `senderProvider`。
- 停止指令任何状态都允许发送。
- 不增加 App 侧 `resume` 路径。
- 不绕过 `Governor`。
- 不改变协议文件和生成协议代码。
- 情境模式未来如果增加自动调档，必须使用 `senderProvider(..., automatic: true)`。

### 5. 设置页保持 C 层边界

本轮不扩展复杂设置逻辑，只把页面文案和分组与产品结构对齐：

- 安全：强度上限、停止后的设备恢复方式。
- 人设：仅影响内容表达，不影响设备强度。
- 隐私：本地数据和清除入口。
- 设备/协议：当前协议版本和设备信息。
- 不加入真实密钥、设备 MAC 或医疗数据上传逻辑。

## 接口与数据约定

- 继续使用现有 `HeartState`：
  - `recordMood`
  - `readCard`
  - `toggleFavorite`
  - `moodFor`
  - `streak`
- 继续使用现有 `senderProvider` 作为所有 BLE 指令唯一入口。
- 本轮不修改 `protocol/contract.yaml`。
- 本轮不修改 `protocol/generated/` 或其他协议副本。
- 情绪、收藏、已读、身体笔记均为内存数据；退出 App 后不保证保留。
- 页面层不直接访问 `BleClient`，只读取 `connectedProvider`、`uplinkProvider`，或调用 `senderProvider`。

## 验证方案

本机当前没有可直接调用的 `flutter`/`dart` 命令，因此实现后按以下顺序验证：

1. 检查 Git 工作区，只确认本任务涉及的 App 文件发生变化。
2. 静态检查：
   - import 路径。
   - Widget 类型和构造函数。
   - Riverpod provider 使用方式。
   - `NlMode`、`NlCmd`、`BleDownlink` 等协议类型。
3. Flutter 工具链可用后执行：
   - `flutter pub get`
   - `dart analyze`
   - `flutter test`
4. 手动验收场景：
   - 启动默认进入「心绪」。
   - 三个 Tab 可以切换，标签和截图一致。
   - 选择情绪后当天色块变化，连续天数更新。
   - 卡片可以左右滑动、展开、收藏、复制分享内容。
   - 未连接设备时心绪页没有调档控件。
   - 「我的节奏」停止按钮始终可点击。
   - 拖动 Slider 过程中不发送，松手后只发送一次。
   - 设备断连时普通控制被 Governor 拒绝，但停止仍可发送。
   - 情境漫游和身体笔记不会绕过安全控制链路。

## 默认假设

- 本轮只实现前端交互骨架，不连接云端、不接 SQLCipher、不实现真实 BLE 扫描 UI。
- 情绪和身体笔记先以内存状态验证交互，后续再抽象 Repository 接入持久化。
- 情境漫游本轮不自动控制设备，避免在剧本系统尚未完成时产生未经确认的设备动作。
- 不提交 commit、不推送远程、不切换分支。
