# 亲密时刻 B 层信息架构纠正与完整纵向实现

> 归档来源：本机 GPT Codex 实施计划（2026-08-28）。历史方案，不以本文件覆盖 B3.0 权威规格。完整情景 UI 拆后续短 PR。

## Summary

彻底拆开「情境漫游」与「我的节奏」，不再共用模式选择或人设组件。最终导航固定为：

```text
亲密时刻
├─ 情境漫游
│  ├─ 人设会话列表
│  ├─ 预设人设 / 对话创建人设
│  ├─ 人设预览与使用确认
│  └─ 独立情境会话页
├─ 我的节奏
│  ├─ 自由档位 -> 八档滑动控制页
│  └─ 定时失控 -> 配置页 -> 独立运行页
└─ 身体笔记
   └─ 记录列表 -> 单次详情 -> 自我探索
```

人设、模板、记忆、情境聊天和双模型只属于「情境漫游」；「我的节奏」完全不调用 Agent。「我的」只保留设备、安全词、隐私和数据管理，不再展示人设。

## Key Changes

### 情境漫游

- 将入口改成微信式人设会话列表，每行显示头像、人设名、最近安全摘要和时间，点击后进入人设预览，不直接开始设备操作。
- 右下角新增创建按钮，下一层提供两个明确入口：
  - `选择预设人设`：按温柔、强势、SM、陪伴等沟通风格筛选。
  - `对话创建人设`：通过引导对话生成草稿，用户预览并确认后才能保存。
- 人设预览页展示性格、表达方式、允许的硬件 Skill、记忆范围和数据使用说明；选择页与使用页严格分离。
- 独立情境使用页采用微信式聊天界面，支持文字、按住说话、打断播放、人设切换抽屉和常驻状态栏。
- Chat 9B 与 Control 9B 只在情境会话中并行：
  - Chat 处理对话、人设表现和待确认记忆。
  - Control 只读取聚合后的温度/压力趋势并产生待确认 Skill 建议。
  - 建议必须经过用户确认、`Governor`、`sendCommand()` 和设备规则。
- 增加可展开的“数据如何流动”面板，逐轮显示脱敏流程，不展示系统提示词、原始传感数组、安全词、密钥或设备地址。
- 人设、对话、关系记忆、模板和偏好分别存储并按人设隔离；提供单条记忆、人设及其关联数据的删除入口。

### 我的节奏

- `/intimacy/control` 改为纯选择页，只显示两个入口，不出现 Slider、人设或情景按钮：
  - `自由档位`
  - `定时失控`
- `自由档位`进入独立控制页：
  - 1–8 档离散 Slider，只在松手时发送 `set_level`。
  - 大停止按钮单独表示档位 0。
  - 不显示情景、失控或人设切换。
- `定时失控`分为配置页和运行页：
  - 配置页输入 1–15 分钟，并提供 3、5、10、15 分钟快捷值。
  - 开始前选择 1–8 档；进入运行后仍可调整档位，但不能设为 0。
  - 展示从本地审核文案库随机轮换的卫生与安全提示，不用 LLM 临时生成医疗建议。
  - 开始前检查设备连接、安全词、麦克风监听和硬件保护状态。
- 运行页显示设备本地倒计时、当前档位、八档 Slider、麦克风监听状态和实体停止说明；拦截普通返回、切模式、缩短、延长和结束会话。
- 提前停止只接受：
  - Android 本地离线语音安全词。
  - K10 摇杆长按或 A+B 实体急停。
  - 断连、传感器保护、监听故障或固件硬超时。
- 倒计时结束后设备发送停止并进入闩锁；App 和后端都不能远程恢复。

### 安全词、协议与后端

- 在「我的 → 安全设置」增加单一安全词输入框，不要求重复输入；保存后通过一次语音测试确认识别效果。
- 安全词仅加密保存在 Android 本地，不上传后端、不进入日志、不进入 Agent 上下文；支持修改和彻底删除。
- Android 增加离线关键词监听服务及麦克风前台服务通知；失控模式启动后监听异常即走安全停止。
- 扩展唯一协议契约：
  - 追加 `start_wild` 命令，不改变现有枚举线序。
  - 下发 `duration_s` 和初始 `level`。
  - 上报 `wild_state` 与 `wild_remaining_s`。
  - 最大时长保持 900 秒，由 K10/玩具侧单调时钟持有。
- 失控运行中允许手动 `set_level(1–8)`，拒绝档位 0、模式切换、远程延时和 `resume`。
- 协议变更从 `protocol/contract.yaml` 生成 Dart、JavaScript、Python、C 和 Schema 产物，不手改生成文件。
- 将现有固定 `/v1/persona` 数据迁移为持久化 Persona CRUD，并保留兼容读取入口；复用现有模板、记忆、偏好和 `/v1/agent/parallel-turn` 契约。
- 使用 SQLite + SQLAlchemy/Alembic 完成本地开发持久化，模型保持 PostgreSQL 可迁移；删除人设时级联清理其会话、记忆、模板和偏好。
- 修订 B 层技术文档中错误的“我的节奏包含人设”结构，并同步实时实施记录、协议说明和 Android 状态。

## Test Plan

- 导航验收：亲密时刻只有三个平行入口；人设只出现在情境漫游；我的节奏只有自由档位和定时失控；我的页面不再显示人设。
- 情境验收：预设选择、对话创建、预览确认、独立聊天、语音输入、双模型并行、数据流展示、记忆确认与删除均可完成。
- 自由档位验收：八档显示稳定，仅松手发送；停止始终走 `sendCommand()`；断连时其他命令被 `Governor` 拒绝。
- 失控验收：输入校验、快捷时间、开始握手、设备倒计时、运行中调档、返回拦截、安全词停止、实体急停、断连停止、监听故障停止、到时闩锁全部覆盖。
- 隐私验收：安全词不出现在网络请求、Agent 上下文、日志、数据库和身体笔记中；删除后本地不可恢复。
- 自动检查：前端测试、后端 pytest/ruff、协议生成器 `--check`、Android 单元与仪器测试、固件编译、360×800 单手布局截图和 debug APK 构建。
- 更新现有 Draft PR #6，明确记录测试结果、APK 状态、固件状态和仍未接真机验证的项目，不自动合并。

## Assumptions

- 继续使用共享 Web/PWA UI 加 Android WebView 原生桥，不复制一套 Compose 页面。
- 当前 `feat/body-notes-insight` 与 Draft PR #6 继续承载本次纠正，避免拆出互相依赖的第二个 PR。
- 浏览器预览可以模拟失控页面，但真实失控启动仅允许 Android App 与 K10 都在线时执行。
- “不能停”仅指普通界面退出无效；语音安全词、实体急停、监听故障、断连保护、传感器保护和设备硬超时始终不可关闭。
