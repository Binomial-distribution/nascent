# PR #16 台词情感、可选 TTS 与假克隆

> 日期：2026-08-29
> 分支：`feat/scenario-boyfriend-personas`
> 不自动写入密钥。小米 MiMo / MiniMax 的 key 只放本机 `software/backend/.env`。

## 目标

Chat 9B 每一轮产出两样东西：

- `dialogue`：能念出口的中文（括号旁白可以给她看，TTS 会剥掉）
- `tts_style`：这一句的语气（温柔 / 俏皮 / 低语 / 平静 / 着急 / 开心），**不进音频**

链路仍是 VAD → ASR → Chat 9B → TTS，不换成本地 Whisper / Qwen3-TTS。

```text
用户说话
  -> /v1/speech/transcribe（PCM 止于 ASR）
  -> /v1/agent/turn（dialogue + tts_style，action 必须为 null）
  -> /v1/speech/speak（只念剥净台词；MiniMax 用 emotion 字段，MiMo 把风格放 user 消息）
```

## TTS 两家

| 提供方 | 怎么带情感 | 人设默认声 |
|---|---|---|
| MiniMax（默认） | `voice_setting.emotion`，由 `tts_style` 映射 | 顾深 `junlang_nanyou`，阿北 `male-qn-qingse`，阿月 `danya_xuejie` |
| 小米 MiMo | user 消息写风格，assistant 消息写纯台词 | 男友映射 Milo/Dean，阿月映射茉莉 |

设置页可切换 `minimax | mimo`。ASR 本轮仍走硅基 SenseVoice。

## 自定义克隆

自定义人设可以上传一段音频，**本轮只记在本地**，不调用 `POST /v1/speech/clone`。后端克隆接口保留给以后。通话仍用人设系统音色。
